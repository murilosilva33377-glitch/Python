# Exercícios de Python - Curso em Vídeo 🐍

Este repositório foi criado para consolidar e demonstrar meu aprendizado prático na linguagem Python, desenvolvido ao longo do curso ministrado pelo professor Gustavo Guanabara no canal Curso em Vídeo.

## 🎯 Objetivo

Fortalecer conceitos teóricos através da resolução de desafios práticos, evoluindo desde a sintaxe básica até estruturas de dados e lógica de programação mais complexas.

## 🚀 Principais Conceitos Praticados

- **Fundamentos:** Tipos primitivos, entrada/saída de dados e operadores aritméticos.
- **Estruturas Condicionais:** Uso de `if`, `elif` e `else` para controle de fluxo.
- **Estruturas de Repetição:** Loops com `while` e `for`.
- **Coleções de Dados:** Manipulação de Listas, Tuplas e Dicionários.
- **Modularização:** Criação de funções (`def`) e utilização de módulos/bibliotecas.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Git & GitHub** (para controle de versão)
